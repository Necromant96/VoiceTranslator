# 🎤 Голосовой переводчик диалогов (Android)

Приложение для реального перевода диалога двух людей, говорящих на разных языках.
Каждый собеседник говорит на своём языке — приложение распознаёт речь, переводит
её и озвучивает на языке второго собеседника, сохраняя историю диалога.

**Без API-ключей и аккаунтов — всё работает «из коробки».**

## Возможности
- 🗣 Распознавание речи (встроенный системный сервис Google)
- 🌐 Перевод (Google Translate + резервный переводчик MyMemory)
- 🔊 Автоматическая озвучка перевода на языке собеседника
- 👤 Две стороны диалога **A ↔ B** — у каждой свой язык и своя кнопка микрофона
- 🔁 Режим «Непрерывно» — не нужно нажимать кнопку после каждой фразы
- 📜 История диалога: оригинал + перевод, цветом по собеседнику
- 📋 Копирование всего диалога в буфер обмена
- 🌍 15 языков: русский, английский, немецкий, французский, испанский, итальянский,
  португальский, китайский, японский, корейский, турецкий, украинский, польский,
  арабский, хинди

## Как установить на телефон (fast путь)

1. **Соберите APK** одним из способов:
   - Откройте папку проекта в **Android Studio** → `Build` → `Build App Bundle(s)/APK(s)` → `Build APK(s)`.
   - Или в командной строке: `gradlew assembleDebug` (нужен JDK 17+).
   - APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
2. **Скопируйте APK на телефон** (кабелем, мессенджером, почтой — как удобно).
3. На телефоне откройте файл и разрешите установку из неизвестных источников
   (Android попросит это один раз).
4. При первом запуске разрешите доступ к **микрофону**.

## Как пользоваться

1. Вверху выберите языки собеседников A и B (кнопка ⇄ меняет их местами).
2. Нажмите «🎤 Говорить (A)» — человек A говорит на своём языке.
3. Когда фраза закончится, перевод появится в диалоге и будет озвучен
   на языке собеседника B.
4. Для реплики B — «🎤 Говорить (B)».
5. Включите галочку «Непрерывно» на нужной стороне — микрофон будет
   включён постоянно, реплики переводятся одна за другой без нажатий.

```
├── java/com/example/voicetranslator/MainActivity.kt — вся логика
└── res/                           — интерфейс и тексты
```

## Технические детали
- minSdk 24 (Android 7.0), targetSdk 36
- Распознавание: `android.speech.SpeechRecognizer`
- Синтез речи: `android.speech.tts.TextToSpeech`
- Перевод: `translate.googleapis.com` (gtx) с фолбэком на MyMemory API
- Зависимостей нет (только стандартные Android SDK)
